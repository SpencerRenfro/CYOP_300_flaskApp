Polytopia

About

Polytopia is a city-building strategy game that takes place in a procedurally generated world. The game is played from a top-down perspective and features a unique hexagonal grid system. The game is currently in early access on Steam.

Battle Calculator

The battle calculator is a tool to help you calculate the outcome of a battle. It is not 100% accurate, but it is a good starting point. It is currently in development and is not yet available.

I made my own version of the battle calculator for Polytopia. I have made this project many times. I first made this project in terminal code in C, then I made it in vanilla javascript then finally in React.
