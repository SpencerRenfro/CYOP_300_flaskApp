Inventory Management

I designed and implemented a inventory management system based off tool sign in / sign out that I used when I was in the military. The system was built using React.js and JSON-server for the database. The system is an SPA and uses React Router for navigation. The user can add, remove, and update tools in the inventory. The user can also sign in and sign out tools. The user can search for tools by name or by category. The user can also filter tools by category, sort tools by name or by category,view a tool's details,view a tool's history, view a tool's current status. As well as creating customers for frequently used customers and signing out tools to them.
